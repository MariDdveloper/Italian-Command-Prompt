## 🚀 Come si avvia

### 🪟 Windows
1. Clicca il pulsante **Scarica per Windows**.
2. Fai **doppio clic** sul file scaricato.
3. Se compare "Windows ha protetto il PC", clicca **Ulteriori informazioni** e poi **Esegui comunque**. È normale: il programma è nuovo e non ha ancora una firma ufficiale.

### 🍎 macOS
1. Clicca il pulsante **Scarica per macOS**.
2. Fai doppio clic sul file `.zip` scaricato: comparirà il programma.
3. Fai **doppio clic** sul programma.
4. Se macOS dice che non può aprirlo, vai in **Impostazioni di Sistema → Privacy e sicurezza**, scendi in basso e clicca **Apri comunque**. Poi rifai doppio clic.

### 🐧 Linux
1. Clicca il pulsante **Scarica per Linux**.
2. Nel gestore file, tasto destro sul file `.zip` → **Estrai qui**.
3. Fai **doppio clic** sul programma estratto.
4. **Se il doppio clic non funziona:**
   1. Trova il file nel gestore file.
   2. Apri un terminale normale.
   3. Trascina il file dentro il terminale.
   4. Premi **Invio**.
5. Se compare "Permesso negato": tasto destro sul file → **Proprietà** → **Permessi** → attiva **Consenti l'esecuzione come programma**, poi riprova.
